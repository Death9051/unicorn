# Хоррор «Собери единорога» — дизайн-документ

Статус: Этап 0 (дизайн, без кода). Документ фиксирует принятые решения.

## Платформа
- Десктоп: **Electron + Phaser** (TypeScript).
- Игра идёт в полноэкранном режиме.
- Управление только мышью: клик и перетаскивание.
- Длительность прохождения: 15–20 минут.

## Языки и распространение
- Языки: **русский и украинский**. Переключение в настройках, по умолчанию — по языку системы.
- Все тексты хранятся отдельно от кода и графики (файлы локализации).
- Текст в графику не рисуется: письмо, инструкция, табличка, кнопки — нарисованная «пустая» основа, текст накладывается кодом. Исключение — логотип: рисуется в двух версиях (RU/UA), символ для «Автора» есть в обеих.
- Игра **не публикуется**, передаётся напрямую (файлом).
- Платформа получателя: **Windows**. Формат: **zip-архив** (распаковать → запустить exe), без установщика и подписи.
- **Портативная версия: ничего не пишется в AppData.** Сохранения, трофеи, настройки и служебные файлы Electron/Chromium хранятся в папке `save/` рядом с exe.
- В архиве лежит `ПРОЧТИ.txt` (RU + UA): распаковать архив перед запуском (не запускать из zip), как пройти предупреждение SmartScreen («Подробнее» → «Выполнить в любом случае»), где лежат сохранения, как сбросить прогресс (удалить `save/`).
- Если папка недоступна для записи (например, Program Files), игра показывает сообщение с просьбой переместить её в другое место.

## Сюжет
- Начало: письмо от тайного Санты — «к сожалению, единорогов не было, высылаю набор для самостоятельной сборки».
- Отправитель анонимен и в игре не появляется. В кадре только игрок (вид от первого лица).
- Инструкция условная: «Найди гриву», «Найди глаза» и т. п.

## Механика
- Один экран (комната). Мелкие загадки открываются крупным планом поверх основного экрана.
- Шаги идут в фиксированном порядке:
  0. Открыть коробку
  1. Грива
  2. Хвост
  3. Рог
  4. Глаза
  5. Ноги
  6. Сердце
- Каждая найденная деталь перетаскивается на единорога.
- Части игрока на единороге реагируют на игрока, животные части «живут своей жизнью», игрушечные неподвижны.
- Подсказки: в инструкции проявляются новые строчки после 30–50 секунд бездействия (интервал случайный).

## Правила
- Детали можно **добывать в любом порядке**, а **ставить** — только в порядке шагов инструкции.
- Поставленную деталь **снять нельзя**.
- Автосохранение после каждого получения и каждой установки детали.
- Трофеи стоят на столе (см. раздел «Трофеи»).
- Для одного слота можно добыть несколько вариантов и выбрать при установке.
- Эффект своей части включается сразу при её получении, а не при установке.
- Неиспользованные детали к концу игры просто остаются в лотке.

## Детали
Туловище и голова существуют только в игрушечной версии и идут в зачёт игрушкам.

| Слот | Игрушка | Животное | Игрок |
|---|---|---|---|
| Туловище | плюшевое | — | — |
| Голова | плюшевая | — | — |
| Ноги | палочки | куриные лапы | своя рука |
| Хвост | пряжа | крысиный | своя жила |
| Грива | нитки | кошачья шерсть | свой скальп |
| Глаза | пуговицы | кошачьи (или рыбьи — открыто) | свой глаз |
| Рог | пластиковый | козий | своё ребро |
| Сердце | заводной механизм | птичье | своё сердце |

### Части игрока
Все части игрока добываются **одним ножом**. Нож лежит на столе с самого начала.
Добывать их можно в любом порядке. Порядок установки — по шагам инструкции (он не меняется). Нарастание жути привязано к числу поставленных деталей, а не к тому, какие части игрок отдал.

| Часть | Эффект (включается сразу при получении) |
|---|---|
| Скальп → грива | с верхнего края экрана иногда стекают капли крови |
| Жила → хвост | элементы интерфейса (лоток, инструкция) «провисают» |
| Ребро → рог | тяжёлое, хриплое дыхание; экран слегка «вздымается» на вдохе |
| Глаз → глаза | половина экрана темнеет. Игрок отдаёт один глаз, у единорога всё равно два (условность) |
| Рука → ноги | курсор дрожит, детали тащатся с запаздыванием |
| Сердце → сердце | замолкает фоновое сердцебиение |

Сам момент, когда игрок отдаёт свою часть, не показывается: экран темнеет, звучит звук.

## Трофеи
Только за концовки, всего 3: «Бездушный», «Химера», «Единорог».
Сохраняются между прохождениями. Стоят фигурками на краю стола, при наведении показывают название.

## Пункт меню «Автор»
- Появляется в меню после первой любой концовки.
- Разгадка не связана с основной механикой сборки.
- **Этап 1 — символы (3 шт.).** На экране «Автор» замок с 3 ячейками, под каждой — подсказка. Символ выбирается из набора (с обманками).
  1. Полянка: символ в текущем состоянии полянки — в траве (пусто) / на табличке «Он ушёл» / на самом единороге. Подсказка: «Спроси у того, кто пасётся. Или пасся.»
  2. Настройки, пункт «Дрожание экрана»: при включении на секунду проступает символ (единственный в настройках). Подсказка: «Он показывается, когда мир дрожит.»
  3. Главное меню, название игры: символ спрятан в логотипе. Подсказка: «Ответ всегда был у тебя перед глазами.»
- **Этап 2 — часы.** Всего этапов два. После этапа 1 на экране «Автор» вместо замка появляется нарисованный циферблат с нужным временем. В новой игре в мастерской нужно выставить это время на настенных часах (пока из них не вынут механизм). Раздаётся стук в дверь, и игра выходит в главное меню. После этого пункт «Автор» открывает экран автора напрямую.
- Награда: экран автора (имя, ссылки, возможно рисованный автопортрет).

## Концовки (по большинству деталей)
- **«Бездушный»**: большинство деталей игрушечные.
- **«Химера»**: большинство деталей животные.
- **«Единорог»**: большинство деталей — части игрока.
- Ничья: решает сердце. Если сердце не из спорящих групп, побеждает более жуткая концовка (игрок > животное > игрушка).

## Полянка (кнопка в меню)
- На полянке живёт последний собранный единорог (реальные детали, собранные игроком).
- Пока концовки нет: пусто и табличка «Тут пока никого».
- **Бездушный**: просто стоит.
- **Химера**: искажения, дрожь, рывки.
- **Единорог**: полянка из человеческих рук. Он смотрит на игрока, откусывает 2–3 руки, затем встаёт на задние ноги и тянется к углу экрана → игра выходит из полноэкранного режима → окно закрывается.
- После такого закрытия при следующем запуске на полянке табличка «Он ушёл».

## Анимации
- Все анимации единорога — кодовые искажения и повороты групп слоёв.
- Заранее нарисованные кадры: только пасть (укус и жевание, голова одна) и рука на полянке (целая → обрубок).

## Графика
- Рисованный стиль, ориентир по манере — «Мистер Томатос» и «Мисс Лимон». Персонажи и мир свои.
- Базовый холст 1920×1080, PNG с прозрачностью.
- Единорог собирается из слоёв на общем холсте («бумажная кукла»), каждая деталь нарисована сразу на своём месте.
- Ноги рисуются двумя слоями (передние и задние), голова — отдельный слой с точкой шеи.
- Чистые контуры, без мягкой полупрозрачной обводки (иначе при искажении будут артефакты).
- Обмен через файлы в репозитории (PSD/PNG), слои с именами по правилу. Экспорт и нарезка иконок — скриптом.
- Позже попробовать PhotoCraft (ArtCraft) через MCP: шаблоны, проверка, экспорт.

## 0.5 Карта экрана — черновик
Сеттинг (предложение): ночь перед Новым годом, гостиная, совмещённая с кухней. Игрок сидит за столом.

Объекты: стол с подставкой, инструкцией и лампой; коробка на полу; ёлка; кресло с котом; клетка с канарейкой; аквариум; голова козла на стене; часы; дверь в коридор; холодильник; комод с 3 ящиками; мышеловка; табурет; полка с банками; лоток для найденных деталей внизу экрана.

Сложность добычи: игрушка — 1–2 клика; животное — небольшая загадка; своя часть — нужен инструмент.

| Слот | Игрушка | Животное | Игрок (инструмент) |
|---|---|---|---|
| Грива | распустить шарф на кресле | вычесать кота щёткой | нож |
| Хвост | клубок под ёлкой | мышеловка + сыр из холодильника | нож |
| Рог | верхушка ёлки (табурет) | голова козла (табурет + отвёртка) | нож |
| Глаза | пуговицы из коробки для шитья в комоде | кот / рыбы (сачок) | нож |
| Ноги | ветки ёлки | куриные лапы из холодильника (разморозить) | нож |
| Сердце | механизм из настенных часов | канарейка (открыть клетку кодом) | нож |

Открытые вопросы: подходит ли новогодний сеттинг; судьба кота; глаза кошачьи или рыбьи.

## 0.9 Требования к графике — черновик (без комнаты)
Раздел «Комната» допишется после карты экрана (0.5).

### Холст и формат
- Игровой экран и исходники — **1920×1080 (1×)**. На мониторах больше Full HD картинка растягивается — принято.
- Цвет: sRGB, 8 бит. Исходник — `.pcraft` (или PSD), экспорт — PNG с прозрачностью.
- Края жёсткие, без мягкой полупрозрачной обводки и свечения (иначе при искажении будут артефакты). Тень, если нужна, — отдельным слоем.
- Текста в графике нет (кроме логотипа).

### Имена
- Слои называются по-русски, в конце в квадратных скобках — код: `Ноги передние — игрушка [legs_toy_front]`. Скрипт берёт только код, по нему же называет PNG.
- Код — латиница, нижний регистр, через `_`: `<слот>_<вариант>[_<часть>]`.
- Варианты: `toy` (игрушка), `animal` (животное), `player` (часть игрока).
- Слои с кодом на `_` (`[_sketch]`, `[_ref]`, `[_guide]`) и слои без кода скрипт не экспортирует.
- Точка вращения — отдельный слой-маркер с кодом `pivot_<имя>` («Точка шеи [pivot_neck]»): маленький круг, скрипт берёт его центр и не экспортирует.

### Единорог (`unicorn.pcraft`)
Один холст, все детали нарисованы на своих местах («бумажная кукла»). Группы сверху вниз (верхняя рисуется поверх):

| Группа | Слои |
|---|---|
| `head` | `horn_toy/animal/player`, `eyes_toy/animal/player`, `mane_toy/animal/player`, `head_toy`, `mouth_bite_01..02`, `mouth_chew_01..02`, `pivot_neck` |
| `legs_front` | `legs_toy_front`, `legs_animal_front`, `legs_player_front` |
| `body` | `body_toy` (с окошком в груди) |
| `heart` | `heart_toy`, `heart_animal`, `heart_player` |
| `tail` | `tail_toy`, `tail_animal`, `tail_player` |
| `legs_back` | `legs_toy_back`, `legs_animal_back`, `legs_player_back` |
| `stand` | `stand` |

- Сердце видно через окошко в груди: в `body_toy` окошко прорезано (прозрачное), сердце лежит под туловищем и бьётся.
- Всё в группе `head` поворачивается вокруг `pivot_neck`.
- Кадры пасти рисуются поверх `head_toy` и совпадают с ним по контуру.
- Экспорт: каждый слой обрезается по содержимому + файл со смещениями, чтобы собрать куклу в игре.
- Иконки для лотка нарезаются из тех же слоёв скриптом: 128×128, с отступом.
