Мастерская: 3D-набросок

Черновая расстановка мастерской из простых фигур, чтобы было по чему рисовать. Сверху панорама глазами Софии, сидящей за столом: 4480×1080, пунктиром отмечен стартовый экран 1920×1080, по бокам по 2/3 экрана. Ниже ту же сцену можно покрутить мышью.
